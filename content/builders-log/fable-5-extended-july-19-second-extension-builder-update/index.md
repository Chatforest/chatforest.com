On July 13, 2026, [Anthropic extended](https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-stays-free-for-paid-users-until-july-19-as-anthropic-buys-more-time/) included Fable 5 access on paid plans to **July 19, 2026**, confirmed in [Anthropic's own support article](https://support.claude.com/en/articles/15424964-claude-fable-5-promotional-access). This is the second extension in a week — the previous deadline was July 7 (extended to July 12), then July 12 (now extended to July 19).

The 50% higher Claude Code weekly rate limits also [carry through the same date](https://x.com/claudeai/status/2076351399999557669), per Anthropic's own Claude account on X: "We're extending Claude Fable 5 access on all paid plans, as well as keeping Claude Code's weekly rate limits 50% higher, through July 19." The first extension (July 7 to July 12) was [announced hours before that deadline](https://www.digitalapplied.com/blog/anthropic-fable-5-access-extended-july-12-2026); the second (July 12 to July 19) wasn't [announced until after the July 12 deadline had already passed](https://www.republicworld.com/tech/anthropic-pushes-back-claude-fable-5-s-free-access-deadline-to-july-19-2026-07-13-132118), with no advance notice either time.

If you read the [July 11 guide to setting up usage credits](/builders-log/fable-5-july-12-tonight-credits-setup-deadline-checklist-builder-guide/) and acted on it: your usage credits are set up correctly. You have until July 19 before they're needed. The credits setup you did is still correct — nothing about the credit structure changed.

If you haven't set up usage credits yet: the new hard date is **July 19, 2026**. After that, Fable 5 access on paid plans (Pro, Max, Team, select Enterprise) requires usage credits at [$10 per million input tokens and $50 per million output tokens](https://platform.claude.com/docs/en/about-claude/pricing), per Anthropic's own pricing page.

## What Actually Changed

**Old deadline:** July 12, 11:59 PM Pacific  
**New deadline:** [July 19, 11:59:59 PM Pacific](https://support.claude.com/en/articles/15424964-claude-fable-5-promotional-access), per Anthropic's own support article

**What did not change:**
- Credit pricing: [$10/M input, $50/M output](https://platform.claude.com/docs/en/about-claude/pricing)
- How to set up credits: Console → Billing → Enable Usage Credits → Set spending cap
- Claude Code rate limits: still [50% higher than standard limits, now through July 19](https://x.com/claudeai/status/2076351399999557669)

## The Pattern: Three Deadlines in Three Weeks

The extension history now looks like this ([digitalapplied.com](https://www.digitalapplied.com/blog/anthropic-fable-5-access-extended-july-12-2026); [republicworld.com](https://www.republicworld.com/tech/anthropic-pushes-back-claude-fable-5-s-free-access-deadline-to-july-19-2026-07-13-132118)):

| Date | Announced | New Deadline |
|------|-----------|-------------|
| July 7 | Hours before cutoff | July 12 |
| July 12/13 | After the July 12 cutoff had passed | July 19 |

Neither extension came with advance notice. [Anthropic itself said](https://x.com/claudeai/status/2078302415804379218) the reason was capacity: "Demand for Fable has been challenging to predict, which is why we rolled it out to subscription plans in stages, extending access several times as we secured additional capacity."

The practical implication: if July 19 arrives without another announcement, it is the real cutoff. But based on the pattern, another extension is possible. We would not plan around that — set up credits before July 19 if you want to keep using Fable 5.

## Builder Actions

If you're already set up with usage credits: nothing to do. Fable 5 access continues through July 19 on your included allowance.

If you're not set up: visit console.anthropic.com → Billing → enable usage credits and set a spending cap. Five minutes. The [July 11 guide](/builders-log/fable-5-july-12-tonight-credits-setup-deadline-checklist-builder-guide/) covers the full setup and cost math.

If you're using Claude Code: the 50% higher rate limits continue through July 19. No action needed; they apply automatically.
