On July 13, 2026, [Anthropic extended](https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-stays-free-for-paid-users-until-july-19-as-anthropic-buys-more-time/) included Fable 5 access on paid plans to **July 19, 2026**. This is the second extension in a week — the previous deadline was July 7 (extended to July 12), then July 12 (now extended to July 19).

The 50% higher Claude Code weekly rate limits carry through the same date. Both extensions happened hours before the deadline each time, with no advance notice.

If you read the [July 11 guide to setting up usage credits](/builders-log/fable-5-july-12-tonight-credits-setup-deadline-checklist-builder-guide/) and acted on it: your usage credits are set up correctly. You have until July 19 before they're needed. The credits setup you did is still correct — nothing about the credit structure changed.

If you haven't set up usage credits yet: the new hard date is **July 19, 2026**. After that, Fable 5 access on paid plans (Pro, Max, Team, select Enterprise) requires usage credits at $10 per million input tokens and $50 per million output tokens.
