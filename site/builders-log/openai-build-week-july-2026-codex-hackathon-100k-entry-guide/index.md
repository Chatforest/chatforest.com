## What Build Week Is

Build Week is a structured, week-long hackathon organized around OpenAI's Codex. It's not a loose prompt competition — you submit a working project, judged on four criteria (below), and there are daily live sessions across the week to support builders.

The event is global. OpenAI has [40+ in-person and virtual community meetups](https://community.openai.com/t/openai-build-week-exploring-whats-possible-with-codex/1386233) running in parallel with the online challenge, organized by local ambassadors and community groups. Whether you attend one or work solo remotely, the submission funnel runs through Devpost.

Registration and submissions: **[openai.devpost.com](https://openai.devpost.com)**

([Full prize breakdown](https://openai.devpost.com/rules).) The winner announcement is around **August 12** — roughly three weeks after submission close ([official rules](https://openai.devpost.com/rules)).

## What to Build

The event centers on **[Codex](https://openai.com/codex/)**, OpenAI's code generation system. Projects should use Codex meaningfully — not as decoration. OpenAI's suggestion: [“bring the idea sitting in your backlog.”](https://x.com/OpenAIDevs/status/2075294038648148385)

High-signal project shapes based on judging criteria:

- **Automation tools**: Codex managing repetitive dev workflows (CI scripting, test generation, PR summarization)
- **Developer productivity**: Building with GPT-5.6 + Codex for code review, documentation, or refactor suggestions
- **Domain-specific code tools**: Specialized coding assistants for a narrow vertical (legal contract templating, data pipeline generation, infrastructure-as-code)
- **Agent scaffolding**: Projects where Codex is the execution layer, not just a suggestion engine

The judges are looking for projects where Codex does meaningful work, not projects that technically invoke the API once.

## Judging Criteria

Four dimensions, equally weighted ([official rules](https://openai.devpost.com/rules)):

1. **Technical implementation** — Does it actually work? Is the Codex integration substantive?
2. **Design and UX** — Can someone who didn't build it use it?
3. **Potential impact** — Does it solve something real, at meaningful scale?
4. **Quality of idea** — Is the underlying problem worth solving?

Strong submissions communicate the problem, solution, and approach clearly. The Devpost description matters as much as the demo.

## What Codex + GPT-5.6 Gives You

The event is aligned with the broader GPT-5.6 rollout — [Sol, Terra, and Luna went generally available July 9](https://www.engadget.com/2210308/openai-rolls-out-gpt5-6-july-9/). If your project involves:

- Long-horizon agentic code tasks → **Sol** ($5/M in, $30/M out)
- Production code generation at scale → **Terra** ($2.50/M in, $15/M out)
- Latency-sensitive routing, extraction → **Luna** ($1/M in, $6/M out)

([Launch-day pricing per OpenAI](https://simonwillison.net/2026/Jul/9/gpt-5-6/), effective July 9; OpenAI cut Terra and Luna pricing later in July.)

Codex itself sits atop this stack and adds the code-specific fine-tuning, context handling, and tool integration.

## What This Signals

OpenAI launched Build Week the same week [GitHub Models runs its first scheduled brownout (July 16)](https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026/) — part of GitHub's wind-down toward full retirement on July 30 — and four days after [GPT-5.6 went generally available](https://www.engadget.com/2210308/openai-rolls-out-gpt5-6-july-9/) on July 9. The sequencing is deliberate: OpenAI is pulling developers toward its own stack as the free-hosting alternatives disappear.

The Codex focus is also notable. [Cursor's enterprise spend share has slid from 41% in June 2025 to 26% by May 2026](https://axis-intelligence.com/cursor-ai-statistics/), driven largely by competition from Claude Code — a decline that predates but forms the backdrop to [SpaceX's $60B agreement to acquire Cursor's parent company, Anysphere](https://techcrunch.com/2026/06/16/spacex-to-acquire-cursor-for-60b-in-stock-days-after-blockbuster-ipo/), announced June 16, 2026. OpenAI has an interest in showing that building with Codex directly, without an IDE intermediary, is viable. Build Week is partly a proof-of-concept campaign.

For builders: the competitive window on this hackathon is real. Seven days is short enough that deep-pocketed teams have limited compounding advantage. A sharp vertical tool with clear demo beats a broad platform with poor communication.
